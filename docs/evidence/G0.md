## Écarts et limites

- PHP 8.3.6 en développement contre 8.4 visé par le plan : Laravel 13 accepte 8.3 ; la cible dépend de l'hébergeur (Q01).
- La preuve de schéma porte sur MySQL 8.4.9. Une autre version (l'image `mysql:8.4` flottante de CI a servi 8.4.11) peut normaliser différemment certaines métadonnées : la CI est épinglée sur 8.4.9 et `schema-parity.sh` doit être rejoué sur la version réelle de l'hébergeur.
- Dans le bac à sable cloud, l'API GitHub (archives de paquets) est refusée par la politique réseau : Composer installe depuis les dépôts git publics et `tools/dev/seed-composer-cache.sh` reconstruit l'archive de `phpstan/phpstan` au commit exact du verrou. Sans effet sur la CI GitHub ni sur l'hébergement.
- Le dépôt GitHub est **public** : il ne doit contenir que des données fictives ; le passer en privé est recommandé.

## Décision

G0 est **acquis** pour le développement sur données fictives. Il n'autorise ni import de données du cabinet ni mutation réelle ; F05 (identité, permissions, bootstrap gérante) peut commencer.
